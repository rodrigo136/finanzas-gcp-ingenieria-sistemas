02 / FORMULACIÓN

Modelo matemático

Se representa la asignación mediante un sistema lineal simétrico y definido positivo de cuatro ecuaciones y cuatro incógnitas.

Variables de decisión

  • x₁Recursos para desarrollo de software (miles de Bs).
  • x₂Recursos para infraestructura TI (miles de Bs).
  • x₃Recursos para seguridad informática (miles de Bs).
  • x₄Recursos para soporte y mantenimiento (miles de Bs).

Interpretación de los coeficientes

Los elementos diagonales aᵢᵢ representan la ponderación de la necesidad y capacidad de absorción de recursos de cada unidad. Los elementos fuera de la diagonal aᵢⱼ representan interdependencias y costos compartidos entre las unidades i y j. La simetría expresa una relación de influencia recíproca dentro del modelo.

El vector b representa las metas financieras ponderadas que deben satisfacerse. Por tratarse de un modelo académico, los coeficientes son parámetros sintéticos y no montos contables directos.

06 / CIERRE

Conclusiones y referencias

Conclusiones técnicas

  • El método de Gradientes Conjugados es apropiado para sistemas simétricos y definidos positivos.
  • El precondicionador de Jacobi puede reducir el efecto de escalas diagonales desiguales y mejorar la convergencia.
  • La calidad de la solución se evalúa mediante el residuo relativo y los errores respecto a la solución directa.
  • La comparación de iteraciones permite observar el impacto del precondicionamiento, sin asumir que siempre será más rápido.

Interpretación organizacional

La solución representa una distribución ponderada de recursos entre unidades que comparten dependencias operativas. En una aplicación real, los coeficientes deberían estimarse a partir de presupuestos históricos, costos, prioridades y reglas institucionales, y el resultado tendría que contrastarse con restricciones presupuestarias reales.
